# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

Only the latest commit on `main` receives security updates.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security problems.**

Instead, report privately:

1. Use GitHub's [private vulnerability reporting](../../security/advisories/new) if enabled.
2. Or email the maintainer (see the repository owner profile).

Please include:

- A clear description of the issue and its impact.
- Steps to reproduce or a proof-of-concept.
- Affected versions / commits.
- Any known mitigations.

## Response Timeline

- **Acknowledgement:** within 3 business days.
- **Status update:** within 7 days.
- **Fix & disclosure:** coordinated with the reporter, typically within 30 days
  depending on severity and complexity.

We follow responsible-disclosure practices and credit reporters in the
advisory unless they prefer to remain anonymous.
